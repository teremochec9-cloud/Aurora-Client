# Aurora Client

**Aurora Client** is a sleek, modern visual utility client built for **Minecraft 1.21.11** on the **Fabric** mod loader. Created by **terem90**, it focuses on delivering a smooth, highly customizable interface and clean gameplay enhancements without sacrificing performance.

### Key Features
* **Modern Glassmorphic UI:** Features a completely redesigned main menu and an intuitive, smooth ClickGUI featuring rounded corners, blur effects, and customizable theme colors.
* **Customizable HUD:** Includes essential on-screen widgets such as a watermark, FPS & ping counters, coordinates, keystrokes, and an active modules list, complete with a drag-and-drop HUD editor.
* **Utility & Visual Modules:** Comes equipped with handy client-side improvements like Zoom, Fullbright, chat enhancements, low fire, custom crosshairs, and no camera shake.
* **JSON Config System:** Automatic saving and loading of your module states, keybinds, HUD positions, and theme presets.

### Requirements
* **Minecraft:** `1.21.11`
* **Mod Loader:** `Fabric Loader`
* **Required Dependency:** **Fabric API** (for `1.21.11`)

### Installation & Controls
1. Install **Fabric Loader** for Minecraft **1.21.11**.
2. Download **Fabric API** for `1.21.11` and place it into your `.minecraft/mods` folder.
3. Drop the **Aurora Client** `.jar` file into the same `mods` folder.
4. Launch the game and press **Left Ctrl** (default) to open the ClickGUI.
